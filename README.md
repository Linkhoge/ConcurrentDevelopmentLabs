## Getting Started

### Prerequisites

Before running any of the labs, make sure you have the following installed:

1. [Go](https://go.dev/dl/) — the Go programming language
2. [VSCode](https://code.visualstudio.com/) with the [Go plugin](https://marketplace.visualstudio.com/items?itemName=golang.go)

### Running a Lab

1. Clone or download this repository
2. Open the project in VSCode
3. Navigate into the folder for the lab you want to run (e.g. `lab1/`)
4. Open the `.go` file and press **Run** or use the terminal:
   ```bash
   go run main.go
   ```
